# π–π Interaction Analysis

This project analyzes π–π stacking interactions in peptide simulations using MDAnalysis.

## Structure
- `main.py`: Entry point for running the analysis.
- `config.py`: Configuration for sequences, replicates, and frame settings.
- `analysis/`: Contains modular functions for ring detection, π–π stacking, and universe loading.
- `data/`: Stores output data and plots.

## Requirements
Install dependencies using:
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```
